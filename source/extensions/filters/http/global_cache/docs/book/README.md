# Envoy Global Cache 필터 구현 가이드

> **C++ 비경험 개발자를 위한 Envoy HTTP 필터 개발 완전 정복**
> 
> Go/Python/Java를 아는 5년차 개발자를 위한 현대적 C++ 캐시 시스템 해설서

---

## 이 책에 대하여

이 책은 Envoy의 `global_cache` HTTP 필터 구현을 통해 현대적인 C++ 시스템 프로그래밍을 배우는 가이드입니다.

### 대상 독자

- Go, Python, Java 등 다른 언어를 잘 아는 개발자
- C++은 생소하지만 시스템 프로그래밍에 관심이 있는 분
- Envoy 확장을 개발하고 싶은 분
- 캐시 시스템의 내부 동작을 이해하고 싶은 분

### 다루는 내용

이 책은 다음과 같은 주제를 깊이 있게 다룹니다:

- **Modern C++**: 스마트 포인터, move semantics, RAII 등 현대적 C++ 패턴
- **비동기 프로그래밍**: Envoy의 이벤트 루프와 콜백 기반 아키텍처
- **캐시 시스템 설계**: LRU 캐시, Redis 연동, 계층형 캐시 구현
- **분산 시스템 패턴**: Single-flight, TTL 관리, 직렬화
- **Envoy 필터 개발**: 설정, 팩토리, 테스트, 운영

### 학습 방법

각 챕터는 다음과 같은 구조로 이루어져 있습니다:

1. **개념 설명**: 왜 이 기능이 필요한지, 어떻게 동작하는지
2. **코드 분석**: 실제 구현 코드를 한 줄씩 읽으며 이해
3. **실습**: 직접 코드를 작성하거나 수정해보기
4. **트러블슈팅**: 흔히 발생하는 문제와 해결 방법
